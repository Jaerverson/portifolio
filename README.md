# Portfólio

Informações profissionais sobre minhas principais habilidades.

## Estrutura

O projeto continua sendo um site estático desenvolvido com **HTML5, CSS3 e JavaScript**, mantendo os caminhos originais de `modules/styles.css`, `src/scripts.js` e `assets/` para compatibilidade com o GitHub Pages.

A página foi organizada semanticamente com `header`, `nav`, `main`, `section`, `article` e `footer`. A navegação usa âncoras internas em listas, a seção de experiência apresenta uma tabela com `thead`, `tbody` e `tfoot`, e a seção de contato possui formulário com `fieldset`, `legend`, labels associados e validação nativa.

## Publicação

O deploy permanece configurado pelos workflows existentes em `.github/workflows/`, sem alteração da tecnologia ou da forma de publicação do repositório.
